Validates that normal behavioral evidence can pass through the
system-level pipeline without unnecessary escalation.

through the integrated security pipeline.

### Scenario 3 — High-Risk Security Event

Validates that security-relevant evidence can be preserved through
audit, timeline, correlation, and incident reconstruction.
